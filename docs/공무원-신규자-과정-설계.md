# 공무원 신규자 과정 (type: 'rookie') 설계·구현

> 작성: 2026-08-20 · 상태: **구현 완료 (배포 필요)**
> 근거: 신규자(2기) 종이 설문지 (2026. 9. 7 ~ 9. 18, KT인재개발원 / "신규자과정(2기) 설문조사.pdf").

## 1. 개요

공무원 신규자 과정은 설문 문항(19문항 + 불만족 시 주관식 6개)이 표준·지방공공기관 신규자와
모두 달라 별도 과정 유형 `rookie` 로 분리. 기존 `newcomer`(지방공공기관 신규자)는 그대로 유지.

- 과정 문서: `courses/{id}.type = 'rookie'`
- 회차(rounds)·반(분반) 없음 — 단기과정처럼 기수마다 과정 1개, 학생당 1회 응답(`completed`)
- 강사: 기존과 동일하게 관리자가 웹(강사관리)에서 등록 — 전원 공통(모든 학생이 평가), 5점 만족도만
- 종이 설문의 강사별 '시간배정(과다/적당/부족)'은 **웹에 넣지 않음** (newcomer 때 담당자 결정과 동일 기준)

## 2. 문항 (종이 설문지 기준, 웹 저장 키)

19문항 — 척도 14개(웹 1=최저~5=최고), 주관식 2개(rq10·rq11, 선택 입력), 선택형 3개(rq17~rq19):

| 키 | 종류 | 내용 | 비고 |
|---|---|---|---|
| rq1 | 척도 | 교육기간(2주) 적절성 | 부적절~적절 척도 |
| rq2 | 척도 | 전반적인 교과편성 | |
| rq3 | 척도 | 공직가치 및 직무교육 | +3-1 주관식 |
| rq4 | 척도 | 역량 및 소양 교육 | +4-1 주관식 |
| rq5 | 척도 | 참여학습(분임정책연구, 체육대회) | +5-1 주관식 |
| rq6 | 척도 | 강사선정 | |
| rq7 | 척도 | 교재 및 교안 적절성 | |
| rq8 | 척도 | 평가 방식 적절성 | 부적절~적절 척도, +8-1 주관식 |
| rq9 | 척도 | 과정 운영(일정 안내, 진행 등) | |
| rq10 | 주관식 | 도움이 된 과목 | 담당자 결정(2026-08-20): 과목명 기재 주관식, 선택 입력 |
| rq11 | 주관식 | 개선이 필요한 과목 | 담당자 결정(2026-08-20): 과목명 기재 주관식, 선택 입력 |
| rq12 | 척도 | 교육내용 효과 | |
| rq13 | 척도 | 교육장소(KT인재개발원) 접근성 | |
| rq14 | 척도 | 대강당 강의환경 | +14-1 주관식 |
| rq15 | 척도 | 식당·휴게공간 등 편의시설 | |
| rq16 | 척도 | KT인재개발원 적합성 | 부적합~적합 척도, +16-1 주관식 |
| rq17 | 선택 | 직렬 (행정직/사회복지직/세무직/시설직/기타) | |
| rq18 | 선택 | 연령 (20~50대) | |
| rq19 | 선택 | 성별 (남/여) | |

주관식: `rq3_comment, rq4_comment, rq5_comment, rq8_comment, rq14_comment, rq16_comment`
(불만족 시 개선사항 — 항상 표시, 선택 입력) + `rq10, rq11`(과목명, 문자열 저장)
+ `comment1~3`(소감/개선/건의 — 표준과 동일).

문항 정의 단일 소스: `admin-utils.js`의 `RK_SURVEY` / `RK_SUB_COMMENTS` / `getSurveyConfig('rookie')`.
Cloud Function 검증 키 목록(`RK_SCALE_KEYS`/`RK_CHOICE_KEYS`/`RK_COMMENT_KEYS`)과 **반드시 1:1 유지**.

통계 카테고리(종이 섹션 그대로): 교육기간(rq1) / 교육운영(rq2~rq12) / 교육환경(rq13~rq16).

## 3. 강사 문항 번호

- 웹 화면: 고정 19문항 다음인 **Q20부터** (`main.js instQNumBase()`, `admin-preview.js`).
- OMR/결과폼: 강사 문항이 **21번부터** → export 시트에 20번 결번 1칸 유지.

## 4. 엑셀 export

- 업로드용 '공무원신규자' 시트: 순번 + 문항 1~19 + **결번 1열(20)** + 21번부터 강사(등록 순서 고정, 0응답도 빈 열 유지).
  모든 값 순수 숫자 — 척도는 6-v 반전(서식 ①=최고), 선택형은 보기 번호.
  **10·11열은 주관식이라 빈칸** (열 번호 정합 유지, 내용은 주관식 시트에).
- 주관식 시트: 순번 + 3-1/4-1/5-1/8-1 + Q10/Q11 + 14-1/16-1 + 소감/개선/건의 (`cfg.subjective` 순서).

## 5. 영향 파일

`admin-utils.js`(RK_* 정의·config·normalizeCourseType), `index.html`+`main.js`(학생 흐름),
`attendance/functions/index.js`(submitSurveyResponse 검증), `admin.html`(유형 라디오·미리보기 블록),
`admin-courses.js`(뱃지), `admin-excel.js`(export 분기), `admin-preview.js`(미리보기 렌더).
`admin-stats.js`는 config 기반이라 normalizeCourseType 외 변경 없음. firestore.rules 변경 없음.

## 6. 배포

1. 호스팅: 루트에서 `firebase deploy --only hosting`
2. **Cloud Function 필수**: `attendance/` 에서 `firebase deploy --only functions:submitSurveyResponse`
   — 배포 전의 함수는 rq 문항을 거부하므로 공무원 신규자 설문 제출이 실패함.
